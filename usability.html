E-Commerce Usability Study

Evaluation Platform: Amazon E-Commerce System

Target User Group: General web users


Study Findings

Users took an average of 8 distinct steps and 10 minutes to locate customer support, indicating friction in deep navigation menus.

Recommendation

Implement a persistent floating support button to streamline user assistance and reduce task completion drop-off.
