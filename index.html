Statistical Cryptanalysis

Finding patterns in the unexpected.

A statistical NLP pipeline that uses character frequencies and chi-squared scoring to help make sense of encrypted text.

  • Python
  • Pandas
  • Statistics
Explore the project ↗

Completed in July 2026 as a Girls Who Code project. The Statistical Cryptanalysis Engine includes single-pass O(N) frequency analysis across 95 ASCII characters, vectorized Pandas operations, and chi-squared goodness-of-fit scoring against standard corpora.

Aegis Flow

Small signals. Smarter cooling.

Exploring how sensor telemetry and anomaly detection could reduce indiscriminate cooling in AI server rooms.

  • Python
  • Sensor telemetry
  • Isolation Forest
Explore the project ↗

An in-progress precision-cooling prototype exploring microcontroller telemetry through a Python serial bridge, thermal drift detection, and virtual Kubernetes workload migration. No production deployment or measured savings are claimed yet.
